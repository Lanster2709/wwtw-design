# Preliminary design of a 50,000 PE activated sludge wastewater treatment works

Built in October 2026 to learn wastewater process design.

Scope: design basis, preliminary sizing, aeration energy, costing and a dynamic check
(storm and cold-weather cases). This is a preliminary, textbook-based design, not a
site design. Assumptions and sources are documented in the Excel workbook (Inputs and
Notes sheets).

Status: Step 1 (design basis) complete. Further steps to follow.
